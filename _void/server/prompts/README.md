# 보이드 프롬프트

출처: Notion 「도로랜드_프롬프트」 (2026-11-06 기준). 사건마다 파일 하나이며, 개발 서버의 Gemini가 이 파일을 시스템 프롬프트로 쓴다(`server/void-demo.mjs`).
문서를 고치면 이 폴더의 같은 파일을 고치고 개발 서버를 다시 켠다.

| 확인 사항 | 현재 초안의 기준 |
| --- | --- |
| 2D 전환 조건 | 원인을 정확히 추리하면 전환 |
| NPC 대화 방식 | NPC 증언은 NPC에게 직접 질문 |
| 힌트 제공 시점 | 요청 또는 반복 실패 시 |
| 정답 판정 | 의미 기반 정답·부분 정답·오답 구분 |
| 정비 노트 | 확인된 단서만 기록 |

| 파일 | 사건 |
| --- | --- |
| safari.md | 사파리 (원리: 무게) |
| food.md | 푸드코트 (원리: 순서) |
| carousel.md | 회전목마 (원리: 기울기) |
| viking.md | 회전 바이킹 (원리: 균형) |
| coaster.md | 롤러코스터 (원리: 마찰) |
| sign.md | 도로랜드 전광판 (원리: 연결) |
| parade.md | 최종 사건: 개막 퍼레이드 대작전 (원리: 보유 원리 종합) |
| delivery.md | 마이룸 원격 의뢰: 멈춰 선 선물 상자 (원문에 없어 같은 형식으로 새로 작성) |
| car.md | 챕터 1 마이룸: 오른쪽으로 쏠리는 자동차, 리코가 안내 (원문에 없어 같은 형식으로 새로 작성) |
